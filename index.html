本地管理，按需连接

⌁

本地索引

分类、搜索、收藏、波形和响度保存在本机 SQLite。已有库只读导入，原音频留在原位。

↔

可交互波形

点击任意位置开始试听，再点同一位置暂停／继续。拖动播放头定位，暂停保留进度，音效和音乐都支持。

◌

按需执行

桥接闲置不扫描素材、不轮询时间线、不分析音频。列表最多显示 50 条，分析由用户主动触发。

◆

放得准

开头 / 最响点 / 结尾三种对齐，打击、转场默认“最响的那一下”对准播放头，上升音默认收在切点。

≡

轨道不乱

按分类进固定音轨：转场进「FX 转场」、打击进「FX 打击」、音乐进「MX 音乐」；位置被占自动用下一条同名轨。

⟲

一键批量

按时间线标记或画面切点批量放置，多个候选轮流用、相邻不重复，顺手把响度调齐。

库是你的

原音频可放本机或 NAS，分类与搜索使用本地索引；支持导出、合并、健康检查和深浅主题。

开始使用

  1. 下载完整 Windows 管理器 ZIP 并解压，保留旁边的 resources、DLL 等文件，运行 SfxAssetManager.exe，无需安装 Node.js。
  2. 浏览、搜索和整理素材可独立使用。首次读取旧库索引；没有旧库时可自行添加音频或关联素材库。
  3. 需要连接达芬奇时，运行包内 安装达芬奇桥接.bat。使用 Windows 版 DaVinci Resolve Studio 20.2.2+，推荐 21.1+；安装时按系统提示授权。
  4. 在达芬奇打开 工作区 → 工作流集成（流程整合）→ 素材管理器桥接，回到管理器点“连接／刷新”。旧插件和旧库保留。

工程引用副本存放在本机 project-media 目录，不参与试听缓存自动清理。备份与迁移工程时请同时保留媒体。

常见问题

它会联网吗？收集数据吗？

只有“检查更新”会请求一个 version.json（可在设置里关闭），不上传任何数据。音效库完全在你本机或你指定的网盘 / NAS 文件夹里。

与旧版插件有什么区别？

管理器独立运行，索引和音频分析在管理器内完成；达芬奇中的桥接仅执行明确操作。切换项目后手动刷新，原库新增素材后手动同步。旧插件 v1.7.2 保留为回退入口。

音效／音乐和本地数据存在哪里？

原音频保持原位，本地索引和缓存默认位于 %LOCALAPPDATA%\SfxAssetManager。试听缓存默认 2GiB，交给达芬奇的长期 project-media 副本单独保留。原素材离线时，已缓存的音频仍可使用。

对白避让是自动化曲线吗？

不是。达芬奇脚本接口不能写音量关键帧，插件用“切段 + 避让轨 + 交叉淡化”的方式实现，效果等价；建议配乐定稿后再做。

支持 Mac 或达芬奇免费版吗？

当前发布 Windows x64 便携包。连接达芬奇需要 Studio 的工作流集成接口；Mac、达芬奇免费版和多小时重型工程不在本次验收范围。

完全不占资源吗？

仍会占用内存、CPU 和磁盘。短时测试未发现明显播放退化，但不能承诺所有工程零影响。批量分析、导出和复制建议在暂停播放时执行，详见测试报告。
