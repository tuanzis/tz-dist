安装

  1. 确认是 Windows 版 DaVinci Resolve Studio（官网下载版，20.2.2 以上，推荐 21.1+）。免费版和 Mac App Store 版没有“工作流集成”菜单。
  2. 下载 zip 并解压，关闭达芬奇，双击 Install.bat，在管理员权限提示里点“是”。若弹出 SmartScreen 蓝框，点“更多信息 → 仍要运行”。
  3. 打开达芬奇：菜单 工作区 › 工作流集成 › 音效轨道库。面板是置顶浮窗，拖到屏幕一侧一直开着用。
  4. 升级：解压新版再运行一次 Install.bat，音效库和设置都会保留。升级达芬奇后也请重新运行一次。

常见问题

它会联网吗？收集数据吗？

只有“检查更新”会请求一个 version.json（可在设置里关闭），不上传任何数据。音效库完全在你本机或你指定的网盘 / NAS 文件夹里。

面板能嵌进达芬奇界面吗？

不能，达芬奇不允许第三方插件嵌入，只能是浮动窗口；面板默认置顶并记住位置。

音效 / 音乐文件存在哪里？

默认“文档\达芬奇音效库”，可以在设置里换成任何文件夹。添加的音效复制到 sounds\分类\，音乐复制到 music\分类\。

对白避让是自动化曲线吗？

不是。达芬奇脚本接口不能写音量关键帧，插件用“切段 + 避让轨 + 交叉淡化”的方式实现，效果等价；建议配乐定稿后再做。

支持 Mac 吗？

目前只提供 Windows 安装脚本；插件本体是 Electron，理论上可在 macOS Studio 版运行，但没有测试。
